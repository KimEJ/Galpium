## [0.0.2](https://github.com/KimEJ/Galpium/releases/tag/v0.0.2)

- EmbeddingGemma 2로 이미지, PDF 모든 쪽의 시각적 내용, 오디오 구간을 글로

  유지됩니다.

## [0.0.1](https://github.com/KimEJ/Galpium/releases/tag/v0.0.1)

첫 공개 버전입니다.

- 글·표·이미지를 작성하는 네이티브 편집기와 미리 보기를 갖춘 로컬 Markdown 위키.
- 자료 관리, 참조 수 표시와 원문 구절·쪽 위치에 연결되는 각주.
- 한국어·영어·일본어 오프라인 하이브리드 검색과 화면 언어 지원.
- ChatGPT 데스크톱·MCP 연결, 요청 프롬프트·채팅 출처 기록, 변경 이력,
  보관·복원과 라이브러리 백업.
