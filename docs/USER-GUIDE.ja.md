## インストールと初回起動

Galpium.appをApplicationsフォルダに置いて起動します。アプリにはWikiエンジンと
MCP実行ファイルが含まれています。Node、Docker、サーバーアカウントは不要です。
公開v0.0.1配布版はApple silicon、macOS 14以降が対象で、アドホック署名を使っています。
Appleの公証を受けていないため、macOSで起動の承認を求められた場合は
**システム設定 → プライバシーとセキュリティ**で確認してください。

既定のライブラリは `~/Library/Application Support/Galpium/` です。アプリ設定で
別のライブラリを選択できます。

初回は空のWikiが表示されます。**新規ページ**で直接書くか、**資料を読み込み**で
UTF-8のMarkdown・テキストファイルを保存します。読み込んだファイルは資料一覧に
表示されます。資料を開き、**この資料から新規ページ**を選んで整理を始めてください。

ウインドウを閉じてもアプリはバックグラウンドで動作します。DockのGalpiumアイコンを
クリックするとメインウインドウが再び開きます。**⌘Q**はアプリを終了します。
別途動作しているMCPプロセスは、引き続き同じライブラリを利用できます。

## 表示言語

**設定 → アプリ設定… → 言語**で **システム言語 / 한국어 / English / 日本語** を
選択します。既定ではmacOSの言語の優先順位に従い、対応する言語がなければ英語を使います。
選択は保存され、画面・メニュー・日付表示にすぐ反映されます。作成した文書、資料、タグ、
改訂履歴の内容は翻訳・変更されません。

## 編集と保存

**編集**には **作成・分割・プレビュー** の表示モードがあります。**⌘B**で太字、
**⌘I**で斜体を指定できます。書式メニューから見出し・リスト・引用・コード・リンク・表・
ファイル添付を利用できます。ファイルをドラッグ＆ドロップしたり、クリップボードの画像を
貼り付けたりすることもできます。

入力中のプレビューは、本文・カーソル・韓国語の変換中の入力を変更しません。変換を確定して
から保存してください。**⌘S**または **保存** はページを記録して編集を続けます。
**完了**は変更を保存して閲覧に戻り、**戻る**は未保存の変更を確認します。
表示モードの切り替えや保存を行っても、現在のページの取り消し履歴は維持されます。

ページ設定ではカンマ区切りのタグ、固定、出典、変更概要を設定できます。資料の関連付けは
任意です。直接書いたページに対して別の原本が自動生成されることはありません。
保存した原文やファイルの内容は変更されず、資料名は変更できます。

本文の上限は64 KiB、原文の上限は256 KiBです。大きな原本からページを作成するときは、
原文全体をコピーせず、まとめを書くスペースと出典リンクを入れます。ファイル添付の上限は
150 MiB、MCPで送信する添付ファイルのバイト数の上限は2 MiBです。

## 下書きと競合

入力を少し止めると、編集内容が端末に下書きとして保持されます。これはページの保存とは
別に表示されます。終了後はホームの **保存された下書き → 復旧** から開いてください。
下書きは元の基準となる改訂を保持し、最新のページを自動的に上書きしません。

アプリやAIが先に同じページを変更した場合は、保存を止めて最新の改訂との比較を表示します。
**下書きを新しい改訂として保存**は、確認した下書きを最新ページの新しい改訂として
記録します。比較してから判断してください。以前のページは履歴に残ります。
アーカイブと復元でも改訂のチェックを行います。

## 閲覧と移動

サイドバーの **マイWiki・資料・アーカイブ** は行全体をクリックして移動できます。
選択中の項目は一つだけ表示され、ポインタを重ねると行が強調されます。
**マイWiki**に戻るとアーカイブのフィルタが解除されます。ホーム・検索結果・アーカイブ・
資料の一覧も行全体から開くことができ、ポインタを重ねると背景が滑らかに強調されます。

右下の歯車の **設定** メニューから **アプリ設定…・AI連携・Wikiの構造を確認** を
開きます。資料にはサイドバーから移動します。アプリ設定は **⌘,** でも開けます。

上部の戻る・進むボタン、または **⌘[ / ⌘]** でページと原本の移動履歴をたどれます。
macOSのページ間スワイプ設定に従う横方向のスワイプにも対応しています。編集中は入力や
横スクロールを妨げないように移動ジェスチャが無効になります。スワイプすると文書領域が
指に合わせて移動し、方向が表示されます。キャンセルすると元の位置に戻り、移動を確定すると
前後の文書へ短いフェードで切り替わります。

**⌘K**で検索欄にフォーカスします。使用中のページではキーワード検索と韓国語・英語・
日本語の段落単位の意味検索を組み合わせます。別の表現や別の言語の質問でも関連文書を
探せます。タグとアーカイブ状態のフィルタはすべての結果に適用され、資料のテキストや
PDF本文も意味検索に含まれます。アーカイブ内ではキーワード検索を使います。

EmbeddingGemmaモデルはアプリに同梱されており、文書がなければ読み込みません。
文書を追加すると段落の索引をバックグラウンドで作成し、検索要求を優先します。
準備中はキーワード検索の結果を先に表示します。検索・索引作成の処理が60秒間なければ、
共有ワーカーとモデルを終了します。同じライブラリを使うアプリとMCPはワーカーを共有します。
設定の **モデルとオープンソースのライセンス** で、同梱モデルの利用条件とライセンスを
確認できます。

検索結果の類似度は、その結果に答えが存在する証拠ではありません。ページと原本を確認して
ください。索引は再作成できる派生データで、バックアップやエクスポートの原本と改訂履歴には
影響しません。モデルに問題が起きてもキーワード検索は利用できます。

`[[page-slug]]` はWikiページ、`[原本](source:source-slug)` は出典へのリンクです。
**その他 → リンクをコピー**でページの識別子を取得できます。**出典と被リンク**では
原本と被リンクを確認できます。安全なHTTP・HTTPS・メールリンクを開くことができます。
外部画像はリンクとして表示し、自動的にはダウンロードしません。HTMLは実行せず、原文の
テキストとして扱います。
既存のローカルチャットへの `codex://threads/<chat-UUID>` リンクはChatGPTデスクトップで
開きます。新しいチャットの作成や設定変更などのアプリ操作リンクは出典に使えません。

## 履歴、アーカイブと復元

**その他 → 履歴**で改訂を選択し、現在のページと比較できます。復元は過去のタイトル・
本文・出典・タグ・固定状態を、新しい有効な改訂として取り込みます。
**ページをアーカイブ…**は内容・履歴・添付ファイルを保持します。アーカイブから再び
復元できます。

**Wikiの構造を確認**はリンク切れ・孤立したページ・未整理の原本・添付ファイルの不足を
表示します。文章の事実関係を検証する機能ではありません。

## 資料と脚注

サイドバーの **資料** で、テキスト・PDF・画像・その他のファイルを一つの一覧で管理します。
上部の検索は名前と読み取り可能な本文を対象にします。**資料を追加**でファイルやテキストを
追加するか、一覧にファイルをドラッグ＆ドロップしてください。行をクリックすると詳細が
開きます。PDFは **プレビュー / テキスト** を切り替えられ、画像には縮小プレビューが
あります。画像やスキャンPDFのOCRは提供していません。読み取り可能なテキストがない資料は
名前で検索できます。

参照数をクリックすると、現在のページ・資料・下書き・履歴からの参照を確認できます。
**…**から名前の変更、外部アプリで開く、Finderで表示、アーカイブ、復元、削除を行えます。
参照されている資料は削除できません。アーカイブの **ページ / 資料** フィルタで種類ごとに
復元します。ファイル名を変更しても拡張子は維持されます。

ページ設定で資料を関連付けるか、**引用…**を選択します。原文のページと実際の一節を選び、
**脚注を挿入**すると本文の番号と文書下部の脚注がつながります。原文にない一節は挿入
できません。番号をクリックするとポップオーバーで引用を確認でき、**原文を表示**から
該当位置を開けます。脚注の横にある戻るボタンは引用した文に戻ります。通常の説明用の脚注も
使えます。Markdownの編集とエクスポートでは `[^ref-id]` / `[^ref-id]: 内容` の形式を
維持します。

検証済みの脚注は、資料ID、原文ハッシュ、抽出スナップショットID、ページと引用した一節を
改訂に保存します。依頼したプロンプトとチャットリンクは、別のテキスト資料に生成記録として
保存します。同じ **出典URL · 任意** 欄にWebアドレスまたはチャットのディープリンクを
入力してください。ローカルチャットの出典は、資料詳細の **ChatGPTで開く** から元の
チャットに戻れます。記録本文のWebアドレスやチャットのディープリンクも、原文を変更せず
クリックできるように表示されます。

名前の変更・再索引・バックアップからの復元後も、引用した一節は保持されます。
引用が原文に存在することの検証は、文章の事実関係や解釈の妥当性まで保証するものでは
ありません。

## バックアップと読み込み

**Wiki → 全体バックアップ**は、整合性のあるSQLiteスナップショット、添付ファイルの
原本、チェックサムのマニフェストを新しいフォルダに作成します。完了前に失敗した場合は、
完成したバックアップとして表示しません。バックアップフォルダ全体を一緒に保管してください。
使用中のDBファイルだけをコピーするとWAL内の最新の内容を取りこぼす場合があるため、
アプリのバックアップ機能を使ってください。

**バックアップを読み込み**はチェックサムを検証し、既存データと同一の項目だけを再利用します。
同じ識別子で内容が異なる場合はエラーで中断し、既存のWikiは変更しません。
ページ・原本・履歴・添付ファイル・ログを読み込み、既存の端末上の下書きは上書きしません。
ファイル処理の途中でキャンセルできます。保存済みの添付原本は、キャンセルやページの
アーカイブによって削除されません。

Markdownエクスポートは本文を保持します。内部のページ・出典・添付ファイルへの参照を
すべて保存するには、Galpiumの全体バックアップを使用してください。

## AI連携

MacのメニューバーにあるGalpiumの本アイコンで、現在のWikiのMCP接続状態とクライアント
一覧を確認できます。接続中は開いた本、未接続は閉じた本で表示します。要求の処理状況は
メニューで確認できます。**Galpiumを開く**は閉じたアプリウインドウを再び開きます。
メニューには **AI連携設定** と **MCP接続を確認** もあります。現在の状態表示を使うには、
古いバージョンで動作中のMCPクライアントを再接続してください。

**設定 → AI連携**で接続情報を確認します。CodexプラグインにはMCPの接続設定が
含まれているため、プラグインから接続できます。手動で接続する場合は設定をコピーし、
Codexの `config.toml` に追加します。アプリがApplicationsにある場合：

```toml
[mcp_servers.galpium]
command = "/Applications/Galpium.app/Contents/MacOS/galpium-mcp"
```

この設定をCodexの `config.toml` に追加します。別のライブラリを使う場合は
`args = ["--library", "/absolute/path/to/library"]` を指定します。プラグインは同じMCPに
加え、資料収集・検索・脚注引用・安全な更新のスキルを提供します。
設定形式は [OpenAI公式MCPドキュメント](https://developers.openai.com/codex/mcp)に従います。

ChatGPTデスクトップのローカルチャットにインストールする場合は、配布ZIPを **展開** し、
**Install Galpium Plugin.command**を実行します。先にGalpium.appとChatGPT.appを
Applicationsにインストールしてください。インストーラはChatGPTに同梱されたランタイムで
ローカルマーケットプレイスを登録し、プラグインを有効にします。別途Codex CLIをインストール
したり、`config.toml` を手動で編集したりする必要はありません。インストール後にChatGPTを
再起動し、新しいローカルチャットで **@Galpium** を選択してください。

**プラグインアーカイブのアップロード**は、サーバーにパッケージを登録する別の経路です。
この配布ファイルは現在のMacでGalpiumを実行するローカルマーケットプレイス用です。
クラウドChat/Workで使うには、別途リモートMCP接続が必要です。
ローカルマーケットプレイスへのインストールは [OpenAI公式プラグインドキュメント](https://developers.openai.com/plugins/build/plugins#install-a-local-plugin-manually)に従います。

ソースリポジトリからインストールする場合は、次を使います。

```sh
sh scripts/install-plugin.command
```

**MCP接続を確認**は、同梱された実際のMCPプロセスを起動し、初期化と21個のツール一覧を
確認します。

検索の埋め込みは同梱のローカルモデルで処理します。接続したAIクライアントが資料を読み、
整理し、そのクライアントの外部送信ポリシーが適用されます。検索結果があるだけで事実と
判断せず、現在のページと原本を読んでください。

## ライブラリの選択とアップグレード

設定の **ライブラリを開く・作成…** で、既存のGalpiumフォルダまたは新しい空のフォルダを
選択します。以前のフォルダはそのまま残ります。アプリとMCPは同じ選択を使い、
MCP設定に別のパスを明示した場合は、そのパスが優先されます。

保存形式v1・v2は、初回起動時にバックアップを作成してからv3に変換します。原文の本文と
既存の改訂スナップショットを保持し、現在のページ・出典の関係と検索索引を構築します。
変換に失敗した場合は以前の形式に戻り、古いアプリが新しいバージョンのライブラリを
上書きすることはありません。

完了・案内の通知は4秒後に自動で閉じます。新しい通知が出ると表示時間が再び始まります。
エラーは内容を確認できるよう、閉じるボタンをクリックするまで表示されます。
