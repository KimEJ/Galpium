## [0.0.2](https://github.com/KimEJ/Galpium/releases/tag/v0.0.2)

- Added offline text-query search across images, all PDF page visuals and audio
  segments with EmbeddingGemma 2.
- Added navigation from search results to a matching PDF page or audio segment.
- Rebuilds existing material indexes for the new model while retaining originals,
  citations and revision history.

## [0.0.1](https://github.com/KimEJ/Galpium/releases/tag/v0.0.1)

Initial public release.

- Local Markdown wiki with a native editor and preview for text, tables and images.
- Material management with reference counts and footnotes linked to original
  passages and page locations.
- Offline hybrid search and an interface in English, Korean and Japanese.
- ChatGPT desktop and MCP integration, request and chat provenance, revision
  history, archive and restore, and library backups.
