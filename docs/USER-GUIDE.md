## 설치와 첫 실행

Galpium.app을 Applications 폴더에 두고 실행합니다. 앱에는 위키 엔진과 MCP
실행 파일이 포함되어 있습니다. Node, Docker, 서버 계정은 필요 없습니다.
공개 v0.0.1 배포본은 Apple silicon과 macOS 14 이상용이며 임시 서명(ad-hoc) 상태입니다.
Apple 공증을 받지 않았으므로 macOS에서 실행 승인을 요구하면
**시스템 설정 → 개인정보 보호 및 보안**에서 확인하세요.

기본 저장소는 `~/Library/Application Support/Galpium/`입니다. 앱 설정에서
다른 저장소를 선택할 수 있습니다.

처음에는 빈 위키가 표시됩니다. **새 페이지**에서 직접 쓰거나 **자료 가져오기**로
UTF-8 Markdown·텍스트 파일을 보관합니다. 가져온 파일은
자료 목록으로 들어갑니다. 원본에서 **이 자료로 새 문서**를 선택해 정리하세요.
창을 닫으면 앱은 백그라운드에 남습니다. Dock의 Galpium 아이콘을 누르면 주 창을
다시 엽니다. ⌘Q는 앱을 종료하며 별도로 실행된 MCP는 같은 저장소를 계속 사용할 수 있습니다.

## 표시 언어

**설정 → 앱 설정… → 언어**에서 **시스템 언어 / 한국어 / English / 日本語**를 선택합니다.
기본은 macOS의 언어 우선순위이며 지원 언어가 없으면 영어를 사용합니다.
선택은 저장되고 앱 화면·메뉴·날짜 표시가 즉시 반영됩니다. 작성한 문서·자료·태그·이력의
내용은 번역하거나 변경하지 않습니다.

## 편집과 보존

**편집**은 작성·나란히·미리보기 모드를 제공합니다. ⌘B 굵게, ⌘I 기울임,
서식 메뉴의 제목·목록·인용·코드·링크·표와 파일 첨부를 사용할 수 있습니다.
첨부파일을 끌어 놓거나 클립보드 이미지를 붙여 넣을 수 있습니다.

입력 중 미리보기는 본문·커서·한글 조합을 바꾸지 않습니다. 한글 조합을 마친
뒤 저장할 수 있습니다. ⌘S 또는 **저장**은 문서를 기록하고 편집을 유지합니다.
**완료**는 변경을 저장하고 읽기로 돌아갑니다. **문서로**는 미저장 변경을 확인합니다.
보기 모드를 바꾸거나 저장해도 현재 문서의 실행 취소 기록을 유지합니다.

문서 설정에서 쉼표로 태그를 입력하고 고정·출처·변경 요약을 설정합니다.
자료 연결은 선택 사항입니다. 직접 작성한 문서는 별도 원본을 자동 생성하지 않습니다.
보존된 원문·파일 내용은 변경하지 않으며, 이름은 바꿀 수 있습니다.

본문은 최대 64 KiB, 원본은 최대 256 KiB입니다. 큰 원본으로 문서를 만들 때는
전체 원문 대신 정리할 공간과 출처 링크를 넣습니다. 파일 첨부는 최대 150 MiB,
MCP를 통해 보내는 첨부 바이트는 최대 2 MiB입니다.

## 초안과 충돌

편집 내용은 입력을 잠시 멈추면 기기에 초안으로 보관됩니다. 이는 문서 저장과
구분되어 표시됩니다. 종료 후 홈의 **기기에 보관된 초안 → 복구**로 다시 여세요.
초안은 원래 기준 개정을 유지하며 자동으로 최신 문서를 덮어쓰지 않습니다.

앱이나 AI가 같은 문서를 먼저 수정하면 저장을 중단하고 최신본 비교를 표시합니다.
**비교한 초안으로 새 개정 저장**은 확인한 초안을 최신본 위에 기록합니다.
비교 후 결정하며, 이전 문서는 이력에 남습니다. 보관·복원도 개정 검사를 거칩니다.

## 읽기와 탐색

사이드바의 **내 위키**, **자료**, **보관함**은 행 전체를 눌러 이동합니다.
활성 항목은 하나만 표시되고 마우스를 올리면 해당 행이 강조됩니다.
**내 위키**로 돌아가면 보관함 필터가 해제됩니다.
홈·검색 결과·보관함·자료의 목록도 행 전체를 눌러 엽니다. 마우스를 올리면
배경이 부드럽게 강조됩니다.
오른쪽 아래 톱니바퀴 **설정** 메뉴에서 **앱 설정…**, **AI 연결**, **위키 구조 점검**을
엽니다. 자료는 사이드바에서 접근합니다. 앱 설정은 ⌘,로도 열 수 있습니다.
상단의 뒤로·앞으로 버튼 또는 ⌘[·⌘]로 문서와 원본 사이의 탐색 이력을 이동합니다.
macOS의 페이지 쓸어넘기기 설정에 따른 수평 스와이프도 지원합니다. 편집 중에는
탐색 제스처가 문서 입력이나 가로 스크롤을 방해하지 않도록 비활성화됩니다.
스와이프할 때 문서 영역이 손가락을 따라 이동하고 방향 표시가 나타납니다. 취소하면
제자리로 돌아오며, 이동을 완료하면 이전·다음 문서가 짧은 페이드로 전환됩니다.

⌘K로 검색에 초점을 맞춥니다. 사용 중인 문서는 키워드 검색과 한국어·영어·일본어
문단 의미 검색을 결합합니다. 다른 표현이나 다른 언어의 질문으로 관련 문서를 찾을 수
있습니다. 태그와 보관 상태는 모든 결과에 적용되며 자료의 텍스트·PDF 본문도 의미 검색에 포함됩니다. 보관함은 키워드로 검색합니다.

EmbeddingGemma 모델은 앱에 포함되어 있고 문서가 없으면 로딩하지 않습니다. 문서가
추가되면 문단 색인을 배경에서 만들고 검색 요청을 우선 처리합니다. 준비 중에는 키워드
결과를 먼저 보여줍니다. 검색·색인 작업이 60초간 없으면 공유 실행기와 모델을 종료합니다.
앱과 MCP가 같은 저장소를 사용할 때 실행기를 공유합니다. 설정의 **모델 및 오픈 소스
라이선스**에서 동봉 모델의 사용 조건과 라이선스를 확인할 수 있습니다.

검색 결과의 유사도는 질문의 답이 존재한다는 증거가 아닙니다. 문서와 원본을 확인하세요.
색인은 다시 만들 수 있는 파생 데이터이며 백업·내보내기의 원본과 변경 이력에는 영향을
주지 않습니다. 모델 오류 시 키워드 검색을 유지합니다.

`[[page-slug]]`는 위키 문서, `[원본](source:source-slug)`는 출처 링크입니다.
**더 보기 → 링크 복사**로 문서 식별자를 얻습니다. **출처와 백링크**에서 들어오는
링크와 원본을 확인합니다. 안전한 HTTP·HTTPS·메일 링크만 열고, 외부 이미지는
링크로 표시하여 자동으로 내려받지 않습니다. HTML은 실행되지 않는 원문입니다.
기존 로컬 채팅의 `codex://threads/<chat-UUID>` 링크는 ChatGPT 데스크톱으로 엽니다.
새 채팅 생성이나 설정 변경 등 앱 명령 링크는 출처로 사용할 수 없습니다.

## 이력, 보관과 복원

**더 보기 → 변경 이력**에서 모든 개정을 선택하고 현재본과 비교합니다.
복원은 과거의 제목·본문·출처·태그·고정 상태를 새 활성 개정으로 가져옵니다.
**문서 보관…**은 콘텐츠·이력·첨부파일을 유지합니다. 보관함에서 다시 복원할 수 있습니다.
**위키 구조 점검**은 끊긴 링크·고립된 문서·정리하지 않은 원본·첨부 누락을 보여줍니다.
구조 점검은 문장의 사실 여부를 확인하지 않습니다.

## 자료와 각주

사이드바의 **자료**에서 텍스트·PDF·이미지·기타 파일을 한 목록으로 관리합니다.
상단 검색은 이름과 읽을 수 있는 본문을 검색합니다. **자료 추가**에서 파일 또는 텍스트를
추가하거나 파일을 목록에 끌어 놓으세요. 행을 누르면 자료 상세가 열립니다. PDF는
**미리보기 / 텍스트**를 전환할 수 있고 이미지는 축소 미리보기를 제공합니다.
이미지·스캔 PDF의 OCR은 제공하지 않으며, 읽을 수 있는 텍스트가 없는 자료는 이름으로 찾습니다.

링크 수를 누르면 현재 문서·자료와 초안·이력의 참조를 확인합니다. **…**에서 이름 변경,
외부 앱으로 열기, Finder에서 보기, 보관·복원·삭제를 수행합니다. 연결된 자료는 삭제할 수
없습니다. 보관함의 **문서 / 자료** 필터로 각각 복원합니다. 파일 이름 변경은 확장자를 유지합니다.

문서 설정에서 자료를 연결하거나 **인용…**을 누르세요. 원문 쪽과 실제 구절을 선택해
**각주 삽입**을 하면 본문의 번호와 문서 아래 각주가 연결됩니다. 원문에 없는 구절은
삽입할 수 없습니다. 번호를 누르면 팝오버에서 인용 내용을 보고 **원문 보기**로 해당 위치를
엽니다. 각주 옆 돌아가기 버튼은 인용한 문장으로 이동합니다. 일반 설명 각주도 사용할 수 있습니다.
Markdown 편집과 내보내기는 `[^ref-id]` / `[^ref-id]: 내용` 형식을 유지합니다.

검증된 각주는 자료 ID, 원문 해시, 추출본 ID, 쪽과 인용 구절을 개정에 보존합니다.
작성 요청 프롬프트와 채팅 링크는 별도 텍스트 자료에 생성 기록으로 보관합니다.
같은 **출처 URL · 선택** 필드에 웹 주소 또는 채팅 딥링크를 넣으세요. 로컬 채팅 출처는
자료 상세의 **ChatGPT에서 열기**로 돌아갈 수 있습니다. 기록 본문의 웹 주소와
채팅 딥링크도 원문을 바꾸지 않고 클릭할 수 있게 표시합니다.
이름 변경·재색인·백업 복원 후에도 인용한 구절은 유지됩니다. 인용의 존재 검증이 문장의
사실 여부나 해석의 타당성까지 보장하는 것은 아닙니다.

## 백업과 가져오기

**위키 → 전체 백업**은 일관된 SQLite 스냅샷, 첨부 원본, 체크섬 manifest를
새 폴더에 만듭니다. 완료 전에 실패하면 완성된 백업으로 표시하지 않습니다.
백업 폴더 전체를 함께 보관하세요. 사용 중인 DB 파일만 복사하면 WAL의 최신
내용을 놓칠 수 있으므로 앱의 백업 기능을 사용하세요.

**백업 가져오기**는 체크섬을 확인하고 기존 데이터와 같은 항목만 재사용합니다.
다른 내용의 동일 식별자는 오류로 중단하며 기존 위키를 바꾸지 않습니다.
문서·원본·이력·첨부·로그를 가져오고, 기존 기기 초안은 덮어쓰지 않습니다.
파일 작업 진행 중에는 취소할 수 있습니다. 이미 보관된 첨부 원본은 취소나
문서 보관으로 삭제되지 않습니다.

Markdown 내보내기는 본문을 보존합니다. 내부 문서·출처·첨부 참조의 전체 보존은
Galpium 전체 백업을 사용하세요.

## AI 연결

맥 메뉴 막대의 Galpium 책 아이콘에서 현재 위키의 MCP 연결 상태와 클라이언트
목록을 확인합니다. 연결되면 펼친 책, 연결되지 않으면 닫힌 책으로 표시합니다. 요청 처리 상태는 메뉴에서 확인합니다. 메뉴의 **Galpium 열기**는
창을 닫은 뒤에도 앱 창을 다시 열고, **AI 연결 설정**과 **MCP 연결 확인**도 제공합니다.
상태 표시를 적용하려면 이전 버전으로 실행 중인 MCP 클라이언트를 다시 연결하세요.

**설정 → AI 연결**에서 연결 정보를 확인합니다. Codex 플러그인에는 MCP 연결 설정이
포함되어 있으므로 플러그인으로 연결할 수 있습니다. 수동으로 연결할 때는 설정을
복사해 Codex `config.toml`에 추가합니다. 앱이 Applications에 있을 때:

```toml
[mcp_servers.galpium]
command = "/Applications/Galpium.app/Contents/MacOS/galpium-mcp"
```

설정은 Codex `config.toml`에 추가합니다. 다른 저장소를 사용할 때는
`args = ["--library", "/absolute/path/to/library"]`를 명시합니다. 플러그인은 같은 MCP와
자료 수집·검색·각주 인용·안전한 갱신 스킬을 함께 제공합니다.
설정 형식은 [OpenAI 공식 MCP 문서](https://developers.openai.com/codex/mcp)를 따릅니다.
ChatGPT 데스크톱의 로컬 채팅에 설치할 때는 배포 ZIP을 **압축 해제**하고
**Install Galpium Plugin.command**를 실행합니다. 먼저 Galpium.app과
ChatGPT.app을 Applications에 설치하세요. 설치 파일은 ChatGPT에 포함된
런타임으로 로컬 마켓플레이스를 등록하고 플러그인을 활성화합니다. 별도의
Codex CLI 설치나 `config.toml` 수동 편집은 필요 없습니다. 설치 후 ChatGPT를
재시작하고 새 로컬 채팅에서 **@Galpium**을 선택하세요.

**플러그인 아카이브 업로드**는 서버에 패키지를 등록하는 별도의 경로입니다.
이 배포 파일은 현재 Mac의 Galpium을 실행하는 로컬 마켓플레이스용입니다.
클라우드 Chat/Work에서 사용하려면 별도의 원격 MCP 연결이 필요합니다.
로컬 마켓플레이스 설치는 [OpenAI 공식 플러그인 문서](https://developers.openai.com/plugins/build/plugins#install-a-local-plugin-manually)를 따릅니다.

소스 저장소에서 설치할 때는 다음을 사용합니다.

```sh
sh scripts/install-plugin.command
```

**MCP 연결 확인**은 앱에 포함된 실제 MCP 프로세스를 실행하여 초기화와
21개 도구 목록을 확인합니다.

검색 임베딩은 앱에 동봉된 로컬 모델로 처리합니다. 연결된 AI 클라이언트가 자료를 읽고
정리하며, 그 클라이언트의 외부 전송 정책이 적용됩니다. 검색 결과가 있다는
이유만으로 사실을 단정하지 않고 현재 문서와 원본을 읽어야 합니다.

## 저장소 선택과 업그레이드

설정의 **저장소 열기 또는 만들기…**에서 기존 Galpium 폴더 또는 새 빈 폴더를
선택합니다. 이전 폴더는 그대로 남습니다. 앱과 MCP는 같은 선택을 사용하며,
다른 위치를 명시한 MCP 설정은 그 설정의 경로가 우선합니다.

저장 형식 v1·v2는 첫 실행 시 백업 후 v3로 변환됩니다. 원본 본문과 기존 개정
스냅샷은 유지하고, 현재 문서·출처 관계와 검색 인덱스를 구축합니다. 변환 실패는
기존 형식으로 되돌아가며, 새로운 앱 버전의 저장소는 오래된 앱이 덮어쓰지 않습니다.

완료·안내 알림은 4초 뒤 자동으로 닫힙니다. 새 알림이 발생하면 표시 시간이 다시 시작됩니다.
오류 메시지는 확인할 수 있도록 닫기 버튼을 누를 때까지 유지됩니다.
