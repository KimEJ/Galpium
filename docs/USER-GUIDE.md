# Galpium 사용 안내

[English](USER-GUIDE.en.md) · **한국어** · [日本語](USER-GUIDE.ja.md) ·
[README](../README.ko.md)

Galpium에서는 정리한 지식을 **문서**로 작성하고, 근거가 되는 원문과 파일을 **자료**로
보관합니다. 문서를 수정해도 자료의 원본 내용은 유지됩니다. 관련 문서를 연결하고 인용
각주를 달면 나중에 지식의 근거를 다시 찾아볼 수 있습니다.

## 시작하기

앱 설치는 [README의 설치 안내](../README.ko.md#설치)를 참고하세요.
처음 실행하면 빈 위키가 열립니다.

1. **새 페이지**를 누르고 제목과 본문을 작성합니다.
2. **저장** 또는 **⌘S**를 눌러 저장합니다.
3. **완료**를 눌러 읽기 화면으로 돌아갑니다.

기존 파일로 시작하려면 사이드바의 **자료 → 자료 추가 → 파일 가져오기…**를
선택합니다. 자료 상세의 **이 자료로 새 문서**는 해당 자료가 연결된 새 문서를 엽니다.

사이드바의 **내 위키**, **자료**, **보관함**으로 이동합니다. 뒤로·앞으로 버튼,
**⌘[ / ⌘]**, macOS의 페이지 쓸어넘기기 제스처로 이전 화면을 다시 열 수 있습니다.
탐색 제스처는 편집 중에는 사용하지 않습니다.

## 문서 작성

문서를 열고 **편집**을 선택합니다. **작성**은 편집기만, **미리보기**는 렌더링된
문서만 보여줍니다. 창이 충분히 넓으면 **나란히**에서 두 화면을 함께 볼 수 있습니다.

![Markdown 원문과 미리보기를 함께 표시한 Galpium 편집 화면](images/editor.jpg)

*Markdown을 작성하며 결과를 함께 확인합니다.*

**서식** 메뉴에서 제목·목록·인용·코드·링크·표를 삽입합니다. **파일 첨부**를
선택하거나 파일을 편집기에 끌어 놓고, 클립보드의 이미지를 붙여 넣을 수도 있습니다.
**문서 설정 · 출처, 태그와 변경 요약**에서는 태그·고정·연결할 자료·변경 요약을
설정합니다. 태그는 쉼표로 구분합니다.

**저장**은 변경을 기록하고 편집을 계속합니다. **완료**는 저장한 뒤 읽기로 돌아갑니다.
**문서로**를 선택하면 저장하지 않은 변경을 어떻게 처리할지 확인합니다.

## 자료 관리

**자료**에서 텍스트·PDF·이미지·오디오·기타 파일을 관리합니다.
**자료 추가 → 텍스트 추가…**로 복사한 글을 보관하거나,
**파일 가져오기…**로 파일을 추가합니다. 파일을 자료 목록에 끌어 놓아도 됩니다.
가져올 수 있는 파일의 크기는 최대 150 MiB입니다.

자료를 열면 원문 또는 미리보기가 표시됩니다. PDF는 **미리보기 / 텍스트**를
전환할 수 있고 오디오는 플레이어로 재생합니다. 파일의 **열기**는 외부 앱에서 열며,
**Finder에서 보기**는 보관된 파일의 위치를 보여줍니다.

각 자료의 **…** 메뉴에서 이름 변경·보관·복원·삭제를 선택합니다. 파일 이름을 바꿔도
확장자는 유지됩니다. 원본 내용은 직접 수정하지 않으므로 수정한 파일은 새 자료로 추가합니다.
링크 수를 누르면 해당 자료를 사용하는 문서·자료·초안·이력을 확인합니다.
참조가 남아 있는 자료는 삭제할 수 없습니다.

## 검색

**⌘K**로 상단 검색창에 이동합니다. **내 위키**에서는 문서를, **자료**에서는 자료를
검색합니다. 자료는 종류별로 필터링할 수 있고, 문서는 태그로 좁힐 수 있습니다.

키워드뿐 아니라 내용의 의미도 검색하므로 다른 표현이나 다른 언어의 질문으로 관련
항목을 찾을 수 있습니다. 이미지와 PDF 쪽의 시각적 내용, 오디오 구간도 글로 검색합니다.
PDF 결과는 해당 쪽을 열고, 오디오 결과는 해당 구간의 시작 위치를 엽니다.
오디오는 자동으로 재생되지 않습니다.

색인은 자료를 추가한 뒤 백그라운드에서 준비됩니다. 준비 중이거나 의미 검색을 사용할
수 없을 때는 키워드 결과가 표시됩니다. 보관함에서는 키워드로 검색합니다.
검색은 앱에 포함된 모델로 Mac에서 처리됩니다.

이미지·스캔 PDF의 OCR이나 오디오 전사문은 생성하지 않으며 영상 색인은 지원하지
않습니다. 유사한 결과가 곧 질문의 답이나 정확한 인용문을 뜻하지는 않습니다.
검색한 원본을 열어 내용을 확인하세요.

## 링크와 인용 각주

문서의 **더 보기 → 링크 복사**로 `[[page-slug]]` 형식의 링크를 복사해 다른 문서에
붙여 넣습니다. **출처와 백링크**에서는 연결된 자료와 이 문서를 가리키는 문서를 확인합니다.

원문의 구절을 인용하려면:

1. 문서를 편집하고 **문서 설정 · 출처, 태그와 변경 요약**을 펼칩니다.
2. 자료를 찾고 **인용…**을 선택합니다.
3. 원문의 쪽을 선택하고 인용할 구절을 그대로 복사해 입력합니다.
4. **각주 삽입**을 누른 뒤 문서를 저장합니다.

인용 구절이 원문에 존재할 때만 각주를 삽입할 수 있습니다. 읽기 화면의 각주 번호를
누르면 인용을 확인하고 **원문 보기**로 해당 위치를 엽니다. 자료의 이름이 바뀌거나
검색 색인을 다시 만들어도 저장된 인용은 유지됩니다. 이미지·오디오 검색 결과 자체는
검증된 인용 구절로 사용할 수 없습니다.

설명을 덧붙이는 일반 각주도 사용할 수 있습니다.

```markdown
문장에 주석을 연결합니다.[^note]

[^note]: 추가 설명입니다.
```

외부 웹 링크는 열 수 있지만 외부 이미지는 자동으로 내려받지 않고 링크로 표시합니다.

## AI 작업의 맥락 보관

AI로 문서를 정리했다면 요청한 프롬프트와 채팅 링크를 텍스트 자료로 남겨 두고
해당 문서에 연결할 수 있습니다. 이렇게 하면 이후에 요청의 범위와 원래 대화를 확인할 수 있습니다.

텍스트 자료의 **출처 URL · 선택**에는 웹 주소 또는 기존 로컬 채팅의
`codex://threads/<chat-UUID>` 링크를 입력합니다. 지원되는 채팅 링크가 있으면 자료
상세의 **ChatGPT에서 열기**로 돌아갈 수 있습니다. 링크를 열려면 해당 데스크톱 앱과
채팅에 접근할 수 있어야 합니다.

## 초안·변경 이력·보관함

입력을 잠시 멈추면 편집 내용이 기기 초안으로 보관됩니다. 초안 보관은 문서 저장과
다릅니다. 다음 실행에서 **기기에 보관된 초안 → 복구**로 열고 저장하세요.

AI나 다른 창에서 같은 문서를 먼저 수정하면 최신본과 비교하는 화면이 열립니다.
**비교한 초안으로 새 개정 저장**을 선택하면 확인한 초안을 새 개정으로 저장하고
이전 내용은 변경 이력에 남습니다.

**더 보기 → 변경 이력**에서 이전 개정과 현재 문서를 비교하고 복원할 수 있습니다.
복원하면 이전 내용으로 새 개정을 만들며 기존 이력을 삭제하지 않습니다.
**문서 보관…**은 문서와 이력을 유지하면서 보관함으로 옮깁니다.
보관함의 **문서 / 자료** 필터에서 복원할 항목을 찾습니다.

설정 메뉴의 **위키 구조 점검**은 끊긴 링크·고립된 문서·정리하지 않은 원본·첨부 누락
등을 보여줍니다. 글의 사실 여부와 해석은 원문을 읽고 별도로 검토해야 합니다.

## 백업과 내보내기

**위키 → 전체 백업…**에서 저장할 위치를 선택합니다. 백업에는 문서·자료·전체 변경
이력·첨부 원본이 포함됩니다. 만들어진 백업 폴더 전체를 함께 보관하세요.

**백업 가져오기…**는 백업을 현재 저장소에 추가합니다. 이미 있는 동일한 항목은
재사용하고 기기에 보관된 초안은 덮어쓰지 않습니다. 같은 식별자의 내용이 서로 다르면
가져오기를 중단하므로 기존 내용을 임의로 덮어쓰지 않습니다.

**더 보기 → Markdown 내보내기…**는 한 문서의 본문을 파일로 저장합니다.
내부 링크·자료·인용·이력을 함께 보존하려면 전체 백업을 사용하세요.

## AI 연결

ChatGPT 데스크톱의 로컬 채팅에 연결하려면 Galpium과 ChatGPT를 **Applications**에
설치한 뒤 플러그인을 설치합니다.

1. [플러그인 ZIP](https://github.com/KimEJ/Galpium/releases/download/v0.0.2/Galpium-Codex-Plugin-0.0.2.zip)을 다운로드하고 압축을 해제합니다.
2. **Galpium-Codex** 폴더를 엽니다. 안에는 **Install Galpium Plugin.command**,
   **plugin** 폴더, **LICENSE**와 **NOTICE** 파일이 있습니다.
3. **Install Galpium Plugin.command**를 더블클릭하고 **Galpium installed.**가 표시될 때까지 기다립니다.
4. ChatGPT를 **⌘Q**로 종료하고 다시 실행한 뒤, 새 로컬 채팅에서 **@Galpium**을 선택합니다.

설치 파일이 연결 설정을 등록하므로 별도 CLI 설치나 설정 파일 편집은 필요하지 않습니다.
연결한 채팅에서 자료를 찾아 관련 문서를 정리하거나 새 문서로 작성하도록 요청할 수 있습니다.
플러그인은 자료의 인용과 기존 문서의 변경 이력을 함께 유지하도록 안내합니다.

맥 메뉴 막대의 책 아이콘이 펼쳐져 있으면 MCP 클라이언트가 연결되어 있습니다.
메뉴에서 클라이언트 목록과 작업 상태를 확인합니다. 연결 문제가 있으면
**설정 → AI 연결 → MCP 연결 확인**으로 앱의 연결 상태를 확인하고 클라이언트를 다시 연결하세요.

저장·검색은 로컬에서 이루어집니다. 연결한 AI 클라이언트가 위키의 내용을 읽을 때는
해당 클라이언트와 모델 제공자의 데이터 전송 정책이 적용됩니다.

### 다른 MCP 클라이언트

stdio MCP 연결을 지원하는 클라이언트에는 다음 실행 파일을 등록합니다.
설정 형식은 클라이언트에 맞게 적용하세요.

```json
{
  "mcpServers": {
    "galpium": {
      "command": "/Applications/Galpium.app/Contents/MacOS/galpium-mcp"
    }
  }
}
```

다른 저장소를 지정하려면 `"args": ["--library", "/absolute/path/to/library"]`를 추가합니다.
셸 사용과 직접 연동은 [확장 가이드](PORTABILITY.ko.md)를 참고하세요.

## 언어와 저장소 설정

하단 톱니바퀴의 **설정 → 앱 설정…** 또는 **⌘,**에서 설정을 엽니다.
**언어**는 기본적으로 시스템 언어를 따르며 한국어·English·日本語를 선택할 수 있습니다.
화면과 메뉴의 언어만 바뀌고 문서나 자료는 번역되지 않습니다.

기본 저장소는 `~/Library/Application Support/Galpium/`입니다.
**저장소 열기 또는 만들기…**에서 기존 저장소나 새 빈 폴더를 선택합니다.
이전 폴더는 유지됩니다. 저장소를 바꾼 뒤에는 MCP 클라이언트를 다시 연결해 새 저장소를
사용하세요. MCP에 저장소 경로를 별도로 지정했다면 그 경로가 우선합니다.

업데이트 전에는 전체 백업을 권장합니다. 새 검색 모델에 맞춰 색인이 다시 준비되더라도
문서·원본·인용·이력은 유지됩니다. 버전별 변경 사항은 [변경 이력](CHANGELOG.ko.md)에 있습니다.
내장 클라우드 동기화는 제공하지 않습니다.

창을 닫아도 앱은 백그라운드에서 실행됩니다. Dock 또는 메뉴 막대의 **Galpium 열기**로
다시 열고, **⌘Q**로 종료합니다.
